# 从绫开始 · 记忆星图

把「从绫开始」的记忆画成星图。

> [!IMPORTANT]
> **这个插件不单独分发**，安装包与后续更新都在官方群里：**577084969 / 951213204**。
> 仓库只用于存放源码与版本记录。

每一段原子记忆是一颗星：同会话、同实体、文字相近的会连成星座，越重要的星越大越亮。
可以搜一段记忆、按分类或时间筛选，点开一颗星能看到它的来源会话、重要度、衰减曲线和关联记忆。

## 它是什么关系

- 数据来自 `astrbot_plugin_congling`（从绫开始）的数据库，**只读**直连，不写不改
- 两个插件互不依赖：星图没装，从绫照常用；从绫没启动，星图照样能读库
- 不跨插件调接口、不要求对方配合，只认一个文件路径

## 安装

1. 从群里下载 `astrbot_plugin_starmap-*.zip`
2. 解压到 `data/plugins/` 下
3. 重启 AstrBot
4. 浏览器打开 **http://127.0.0.1:6186/**

> 不要从 AstrBot 面板里直接点开插件页面。面板下发的页面地址带一次性登录令牌，
> 手动输入会显示「未授权」，只有面板自己生成的那条链接有效。
> 所以本插件自己起一个只监听本机的小服务，端口可配。

## 找不到记忆库

插件会自动找 `data/plugin_data/astrbot_plugin_congling/congling.db`。找不到时：

1. 打开星图页面，右下角点「注入记忆库」
2. 粘贴 `congling.db` 的完整路径
3. 点「扫描」确认找到多少条记忆，再点「注入」

也可以在「从绫开始」面板 → 记忆 → 记忆星图 里点「复制记忆库路径」。
绑定结果存在 `data/plugin_data/astrbot_plugin_starmap/bind.json`。

## 配置

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `db_path` | 空 | 留空自动找；填目录也可以 |
| `port` | 6186 | 本地服务端口，被占用就换一个 |

## 关联算法

星图的连线不是随便画的，五项加权：

```text
weight = 0.22 × 同会话
       + 0.32 × 实体重合
       + 0.30 × 二元词 Dice 系数
       + 0.13 × 时间衰减（半衰期 18 小时）
       + 0.03 × 同类型
```

阈值 0.38，每个节点最多连 7 条边，两端互选才真正落线（类似 KNN 的互相为邻）。
参数写死在 `core/graph.py`，改之前先想清楚——星图的视觉密度就是按这套调的。

实测：6200 个节点、13800 条边，全量重算约 2 秒，按「条数 + 最大 id」判断失效，TTL 60 秒兜底。

## 接口

```text
GET  /data      原子记忆 + 关联边 + 图元信息
GET  /status    库找到没有、上次构建耗时
POST /scan      校验一个路径是不是记忆库
POST /bind      校验并绑定
```

只读，没有任何写接口。
